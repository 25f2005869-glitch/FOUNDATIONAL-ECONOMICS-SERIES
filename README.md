# 🚀 Getting Started

## Clone Repository

```bash
git clone https://github.com/25f2005869-glitch/FOUNDATIONAL-ECONOMICS-SERIES.git
```

## Enter Repository

```bash
cd FOUNDATIONAL-ECONOMICS-SERIES
```

## Install Dependencies

```bash
pip install -r requirements.txt
```

---

# ▶ Running a Project

Example:

```bash
cd 02-money-currency
```

Run Statistical Analysis:

```bash
python analysis.py
```

Generate Charts:

```bash
python charts.py
```

Run Machine Learning Model:

```bash
python ml_model.py
```

Launch Dashboard:

```bash
streamlit run dashboard.py
```
